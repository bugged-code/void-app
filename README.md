Aplicación web de mensajería tipo **foro privado**, donde los **admins publican mensajes** y los usuarios los reciben en tiempo real.  
El sistema maneja **usuarios con roles** y persiste únicamente la información necesaria.

---

## Características clave

- Inicio de sesión con usuarios persistentes
- Roles (admin / user, extensible)
- Mensajes enviados por admins guardados
- Comunicación en tiempo real
- Backend simple y escalable
- Preparado para cifrado de extremo a extremo
